## Photography Plan

The goal is transcription- and verification-quality images with stable
provenance.

- Use iPhone camera originals as the source of truth.
- Take full-page photos with margins visible before any cropped/scanned copies.
- Take duplicate shots of each page.
- Check focus and page order before moving to the next item.
- Photograph folder labels, call slips, and any useful context separately.
- Do not use flash, external lights, scanners, or any setup that touches the
  material.
- If a stand is not permitted, photograph handheld.
