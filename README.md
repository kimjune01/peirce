# Peirce Primary Sources

Public domain works of Charles Sanders Peirce (1839-1914), transcribed for free access.

Peirce formalized abduction, named methodeutics, and died broke. His manuscripts sat in Harvard's Houghton Library for a century. The editions that publish them are paywalled. The words are public domain.

This repository collects freely available primary texts and (eventually) original transcriptions from the manuscripts.

## Contents

- `1878-deduction-induction-hypothesis.md` — "Deduction, Induction, and Hypothesis." *Popular Science Monthly* 13, Aug 1878, pp. 470-482. The bean syllogism. The three modes named.
- `1908-neglected-argument.md` — "A Neglected Argument for the Reality of God." *Hibbert Journal* 7(1), 1908, pp. 90-112. Musement defined. The three stages of inquiry.
- `HOUGHTON_REQUEST.md` — Request list for photographing manuscripts at Houghton Library, Harvard.
