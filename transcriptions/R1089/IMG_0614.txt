If we write

        ψ₁ = g₁ √(μ₁h₁/ρ₁) · φ₁

        ψ₂ = g₂ √(μ₂h₂/ρ₂) · φ₂

and if we put

        ΣT² = T₁′² + T₂′²
        ΔT² = T₁′² - T₂′²

        Q = (ρ₁ρ₂ - g₁g₂)/(2ρ₁ρ₂ - 1/2(g₁+g₂)²) (g₁+g₂) √(μ₁μ₂h₁h₂/ρ₁ρ₂)

these equations take the form

        (ΣT² + ΔT²) Dₜ²ψ₁ + QDₜ²ψ₂ = -2ψ₁

        (ΣT² - ΔT²) Dₜ²ψ₂ + QDₜ²ψ₁ = -2ψ₂

Let us now take

        u = √(√((ΔT²)² + Q²) + ΔT²) · ψ₁ + √(√((ΔT²)² + Q²) - ΔT²) · ψ₂
        v = √(√((ΔT²)² + Q²) - ΔT²) · ψ₁ - √(√((ΔT²)² + Q²) + ΔT²) · ψ₂

so that

        ψ₁ = √(√((ΔT²)² + Q²) + ΔT²)/(2√((ΔT²)² + Q²)) · u
             + √(√((ΔT²)² + Q²) - ΔT²)/(2√((ΔT²)² + Q²)) · v

        ψ₂ = √(√((ΔT²)² + Q²) - ΔT²)/(2√((ΔT²)² + Q²)) · u
             - √(√((ΔT²)² + Q²) + ΔT²)/(2√((ΔT²)² + Q²)) · v.
